## 迁移闭环：运行中子集，不能当最终成绩

完整分配为 50 个 test episode 的源任务实例 × seeds 17/29/43 × 两种辅助条件，共 300 次。
这是 50 个任务实例，非 50 种独立技能；多 seed 重复不增加独立任务数。
源任务包括原已采样的起点、物体、桌子、目标区域和指令，准备器不重新随机生成一套任务。

本快照完成 **36/300** 次，涉及 **6** 个任务，

子集按执行顺序收集，不能据此估计全 50 个任务的最终能力或断言两种辅助条件有优劣。

不能把这些系统退出全部归因于视觉模型。单例跟踪证据与优先排查项见

## 物理条件与范围

- `source_assisted`：测得闭合、抬升 ≥4cm、TCP 距离 ≤8cm、物体速度 ≤0.30m/s 后添加固定抓取关节，连续打开前释放。
- `no_grasp_assist`：不添加固定抓取关节；仍记录同样的物理事件。

两组都保留操作底座/支撑锁定，禁止中途重置物体；接触采用几何代理，非接触传感器测量。
源 Sim6 任务迁移到 Isaac Sim 5.1，辅助闭合语义与旧 binary counter 有明确差异。
推理时仿真暂停，5 Hz 是观测/动作点率，控制 50 Hz，完整操作块后约 0.5 Hz 重新查询模型。
因此本实验不能证明纯物理、实时或真机部署能力。

后续模型/执行改进用独立 validation 协议，不改变当前冻结 test，也不重用 test 反复调参后宣称独立验收。
复现所需依赖、路径约定与命令见 [开发指南](../joint_trajectory_development_guide.md) 和
[正式评估操作](../formal_joint_trajectory_evaluation.md)。
