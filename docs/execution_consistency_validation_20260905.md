## 1. 先明确能够验证的合同

源归档提供相机对齐的 5 Hz 采样。源流水线先记录 pre-action observation，再下发当前 `decision.action`，再记录 post-step observation；派生标签从 `index+1` 开始。因此第一标签是未来采样时刻的控制目标，不能直接解释为当前时刻的原命令，也不能当作未来实测关节位置。

本轮对照 `u(t)` 与 `u(t+0.2)`，每点保持十个 50 Hz tick。两组使用同一首个采样前状态、相同控制时长；提前一拍组末尾重复最后一个命令，不跨越阶段借用下一阶段标签。此实验可以检查采样与保持合同，不能复现未保存的完整 50 Hz 教师控制。

当前可用物理环境只有 Isaac Sim 5.1。尚未完成源 Sim6 重执行，因此没有“源环境与迁移环境均通过”的结论。源归档中的成功字段仅用于确认示范来源，不是本轮源环境回放结果。

### 无模型回放入口

- `scripts/prepare_execution_validation.py`：校验发布 validation 清单、源归档和文件 SHA256；提取 50 个已有 validation 示范的轻量状态文件，绑定迁移场景。没有新造 50 个任务。
- `scripts/replay_sampled_joint_targets.py`：直接下发源绝对六关节/夹爪目标，不调用 VLM、DiT 或模型服务。
- `--offset 0/1`：单次时序；`--paired-offsets`：依次运行 0、1，需要运行时 `--num-episodes 2`。
- `--physics-profile source_assisted/no_grasp_assist`：分别报告两组；都保留操作底座/支撑锁定。前者仍使用现有连续夹爪验证条件，不能称为原 Sim6 二值辅助的精确复现。

回放仅从首个 `exec_pick` 采样的 pre-action state 开始。在物理评估启用前一次性恢复根位姿/速度、全部关节位置/速度、物体位姿/速度，并检查实际写入误差。夹爪源目标是左右指关节米制位置，按既有 0.04 m 满开行程映射为连续 fraction。之后禁止物体重置。

这是一项隔离抓取阶段的接口诊断：不包含导航到位、运输、放置，不走学习动作的相对量解码/限速裁剪。它既不是完整教师回放，也不是“完美预测通过全部部署链”的最终证明。后续完整链验证还需覆盖这些环节。

`summary.success` 只表示所有采样命令无运行错误地执行完毕；`policy_score=false`、`full_task_success=null` 明确限定用途。物理结果必须读取 `physics_evidence` 及独立的 `diagnostic_lift_hold`，不能把框架的完成标志当成抓取成功率。

`diagnostic_lift_hold` 是新增描述性指标：最后 1 秒的每个控制 tick 同时满足抬升 ≥4 cm、物体到 TCP ≤8 cm、物体速度 ≤0.30 m/s、当前闭合命令 fraction ≤0.5。它使用几何代理而非接触传感器，**不替换**原 `pick_verified`。原判据额外要求实测夹爪 fraction ≤0.5；夹住有宽度物体时这一条件是否漏计，需单独核查。

### 栅格量化的确定证据

实际 tomogram `resolution=0.20 m`。源码将连续 XY 四舍五入到栅格中心，最近中心的平面量化上界为 `sqrt(2)*0.10≈0.1414 m`。因此即使没有额外可行栅格搜索，部分合法连续目标也会超过现有 10 cm snap 门槛。

78 个源超限目标中，51 个 `snap_end_dist=0`；109 个模型超限目标中，75 个为零。该字段表示包含垂直切片移动的 BFS 搜索层数，**不是**物理 XY 距离为零；值为 1 也不代表水平移动了一个栅格。

进一步用实际 tomogram 的 `center` 和 `resolution` 重算 `Q=center+round((A-center)/resolution)*resolution`：**500/500 个源目标和 479/479 个模型目标的 B.xy 均与 Q 完全一致**。本批次的 XY 端点偏移全部与最近栅格中心量化一致，没有观测到额外水平重定位；对应证据 `quantization_decomposition.json`。这不排除其他任务/地图的障碍重定位，也不是浮点误差。

这说明门槛与栅格端点接口存在冲突，并不授权放宽门槛。候选修正是保留连续终点且验证末段碰撞/可达性，或重新构建更细且验证一致的地图；在末段安全验证完成前，本轮不伪造 B=A，也不改地图或门槛。

## 3. DWA 空数组异常已经定位

对既有失败轨迹进行只读取证：PCT 返回两行完全相同的 XY 端点。DWA 将它们加密/去重后只剩一个点，随后投影使用的路径段数组为空，`min` 触发原始异常。当机器人仍在近目标容差内时可能提前返回零速；漂移后继续处理该退化路径才触发异常，因此仅在规划请求时刻探测一次不足以复现。

使用保存的异常前实测站位和重复路径，在显式、非空的无障碍诊断栅格中重现了原始 `zero-size array ... minimum`。这里人为无障碍栅格只用于隔离路径缺陷，不表示原现场无障碍。证据：`dwa-degenerate-reproduction.json`。

当前适配器增加明确失败状态并保留 trace：

- `dwa_invalid_path`：非法路径形状/数据。
- `dwa_degenerate_path`：几何长度为零，进入源 DWA 投影前拒绝。
- `dwa_invalid_map`：缺失、空或无效栅格；合法非空全零栅格仍允许。
- `dwa_no_legal_control_candidates`：采样了控制候选但无可行候选；不与主动到达/转向零速混同。

这项修正防止未分类崩溃并保留失败归因，**不声称已提高导航完成率**。退化局部路径如何在碰撞约束下重新连接到当前位姿，仍需独立验证。

## 4. G/A/B/C 记录与解释边界

运行器新增 `navigation_GABC`，规划拒绝也保留 A/B 证据。G 取任务的名义操作站位，仅供评估，不输入模型；它不是唯一可行站位的真值。A 为请求目标，B 为实际规划端点，C 为执行返回的实测根位姿。

分别报告 A−G、B−A、C−B、C−G、C−A 的 XY 米制距离和独立包角 yaw 误差。PCT 探测没有运动，C 为 null；不能拿 A 或 B 代替 C。仅 `local_goal_reached` 对应既有 0.10+0.12=0.22 m 名义容差组合，窗口耗尽没有此到达保证。十点 NAV ADE 不等价于任何实测停车精度。
